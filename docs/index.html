🛡️

Zero Cloud, Zero History Storage

ClipGum does not maintain a perpetual logging database of your copy history. Your sensitive passwords and credentials stay in volatile RAM and vanish.

🧠

On-Device PrismML Bonsai 4B AI

Meeting summaries, tone rephrasing, and grammar correction running locally via Apple MLX in ultra-fast 2-bit ternary quantization. Never leak confidential IP.

🔗

Instant URL Tracker Purging

Strips invasive query tokens (utm_*, fbclid, gclid, mc_eid) automatically while strictly maintaining original destination links.

🔑

Deterministic Secret Redaction

Instantly recognizes GitHub tokens, AWS keys, Stripe secrets, private keys, and JWTs, safely replacing them with [SECRET_REDACTED] before you hit paste.

📊

Structured Table Transformation

Turn messy web tables, spreadsheets, or TSV snippets into clean, aligned Markdown or CSV formatted for GitHub, Slack, Notion, or terminal docs.

⚡

Localhost & Custom API Support

Seamlessly connect your own local inference engines (Ollama, LM Studio, vLLM) or any OpenAI-compatible endpoint with streaming response support.
